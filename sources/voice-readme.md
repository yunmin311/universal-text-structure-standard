# Voice System V4 — B 级文本结构版

V4 保留 V3 的四份主文档与少文件原则，不扩充新的知识体系；本轮只重构**每个 Markdown 文件内部的信息组织与排版**。统一遵循 B 级文本逻辑：连续解释用自然段，并列信息用 bullet，严格顺序用编号，稳定比较用表格，数据/迁移链用箭头代码块，`## / ###` 只承担真正的父子知识层级。

## 文件与用途

- `01_声音与歌唱_从发声机制到声区共鸣与音色.md`：发声机制、声道/呼吸、构音学习、声区、换声、音色、强声与声稳诊断。
- `02_普通话清晰度_构音声调语流与纠音.md`：普通话音位对立、声调、自然语流、迁移与中文测试。
- `03_英语发音_音素重音节奏与连续语流.md`：英语音素、音节结构、重音节奏、connected speech 与完整测试。
- `04_训练与评估_计划测试排错与长期恢复.md`：开声、日常训练、四周恢复、Baseline、评分、Error Log、安全边界与参考资料。
- `VOICE_STATE.yaml`：可选的最小状态记录，不是每日必填作业。

第一次学习可按 `01 → 02/03 → 04`。之后直接进入对应主文档；不依赖 Wiki Links 或额外索引文件。
