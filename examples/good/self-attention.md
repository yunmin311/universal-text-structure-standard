# Self-Attention：从信息汇聚到可核对的计算

Self-Attention（自注意力）让序列中的每个位置根据当前内容，决定从哪些允许访问的位置读取多少信息，再用这些信息更新自己的表示。它的核心不是“找到最相关的一个词”，而是计算一组权重并汇聚向量；同一个输入位置可以参与多个输出位置的计算。本文从单头计算讲到掩码、多头及 Transformer 中的位置，默认读者知道向量和矩阵乘法，不要求已经理解神经网络。范围限于标准缩放点积注意力，不展开所有位置编码、缓存和加速算法。

## 一、一次注意力计算到底改变什么

模型不能直接对字符串做矩阵乘法，因此先将 token（分词器产生的处理单元，未必等于一个词）变成向量。序列中的每个位置对应一个向量，这些向量按行组成输入矩阵 $X$。在第一层，表示通常来自词元嵌入及位置相关处理；在后续层，表示已经包含先前层计算出的上下文。注意力读取当前层的表示，输出相同数量的新位置表示，并不直接输出下一个词，也不自动缩短序列。

以“她把书放在桌上，因为它太重了”为例，理解“它”需要利用上下文区分可能指代的对象。注意力提供了一条让当前位置汇聚其他位置信息的可学习路径，但这个例子只是说明需求，不能据此宣称模型必然把最大权重分配给“书”。真实权重取决于参数、输入、层和注意力头；某个词对最终预测的重要性也不能仅由一张注意力矩阵确定。

完整的信息路径是：输入表示 → 产生查询、键和值 → 计算匹配分数 → 限制可访问位置并归一化 → 汇聚值向量。这里“自己”指查询、键和值来自同一条序列，不表示只读取自己的位置。允许读取哪些位置是另一个问题：双向注意力可访问整个有效序列，因果注意力只能访问当前位置及之前的位置，填充位置通常还要另外排除。

## 二、Q、K、V 与一行输出的形成

### 1. 三种投影如何分工

Query（查询，Q）表示当前位置用于匹配的特征，Key（键，K）提供被匹配位置的特征，Value（值，V）提供实际参与汇聚的信息。三个名字描述计算职责，不是人为指定的“语法字段”。标准形式用三个可学习矩阵对同一个 $X$ 做线性投影：$Q=XW_Q$、$K=XW_K$、$V=XW_V$。参数通过训练任务共同学习，不需要给每个 token 手工标注它应该查询什么。

设序列长为 $n$，输入宽度为 $d_{model}$，查询和键的宽度为 $d_k$，值的宽度为 $d_v$。查询与键必须有相同宽度，才能做点积；值的宽度可以不同，因为它在权重已经形成后才参与汇聚。忽略 batch（同时处理的样本组）和头数时，整个计算中的形状如下。

| 对象 | 形状 | 在计算中的职责 |
| --- | --- | --- |
| $X$ | $n\times d_{model}$ | 每行是一个输入位置的表示 |
| $Q$、$K$ | $n\times d_k$ | 为每对查询位置与键位置计算分数 |
| $V$ | $n\times d_v$ | 提供各位置被读取的内容 |
| $S$、$A$ | $n\times n$ | 分别保存匹配分数和归一化权重 |
| $O$ | $n\times d_v$ | 每行是一个查询位置汇聚后的输出 |

分开 Q、K、V 的意义是让“怎样匹配”和“传递什么”不必使用同一组特征。即使三者都来自 $X$，它们通常也不相同，因为投影参数不同；查询和键角色不同还意味着从位置 $i$ 看位置 $j$ 的分数，不必等于反方向的分数。不要从“来自同一输入”推导出注意力矩阵对称。

### 2. 分数怎样变成汇聚权重

点积将查询向量和键向量按对应维度相乘后求和，得到一个标量分数。对所有位置一起计算，就得到 $S=QK^T/\sqrt{d_k}$：第 $i$ 行固定查询位置，第 $j$ 列对应被读取的位置。softmax（指数归一化）沿每一行将允许位置的分数转成总和为 1 的权重；它不是沿查询方向归一化，也不是只选最大值。

$$
A_{ij}=\frac{\exp(S_{ij})}{\sum_{t=1}^{n}\exp(S_{it})},\qquad O_i=\sum_{j=1}^{n}A_{ij}V_j.
$$

这组公式先描述没有掩码、分数均有限的情况。在实数运算中，每个权重严格为正；数值实现可能因下溢得到零，加入掩码后禁止位置也应为零。输出 $O_i$ 是值向量的加权和，不是分数的加权和。单头此处的输出位于这些值向量的凸包内，但后续投影、残差和前馈变换不受这一局部结论约束。

缩放因子 $\sqrt{d_k}$ 用于控制点积的典型尺度。若查询与键的各分量相互独立、均值为 0、方差为 1，点积的方差为 $d_k$，除以 $\sqrt{d_k}$ 后方差回到 1；这是解释缩放动机的假设模型，不是训练后参数永远满足的统计定律。分数差距过大容易使 softmax 接近饱和，让部分梯度很小，缩放有助于缓解这一问题，但并不保证所有权重均匀或所有训练都稳定。

### 3. 用两个位置手算一次

取 $Q=K=V=I_2$，即三个矩阵都等于二阶单位矩阵。此时 $d_k=2$，第一行缩放后的分数为 $(1/\sqrt{2},0)$，归一化权重约为 $(0.669762,0.330238)$。第一行输出因此也是这个二元向量：它读取了更多第一个值，但仍混入第二个值；第二行对称地得到 $(0.330238,0.669762)$。这里为了便于手算刻意让 Q、K、V 相同，不能把它当成一般模型的性质。

这个例子把分数、权重和输出区分开了：分数不要求为正，也不要求和为 1；每行权重在本例中非负且和为 1；输出的数值则取决于 V。保持 Q、K 不变而修改 V，会保持本次注意力权重不变，却改变输出；这也是检验自己是否混淆三个角色的一种方法。

## 三、掩码决定可以读什么，位置信息决定怎样区分顺序

### 1. 因果约束与填充约束

Mask（掩码）规定哪些连接被允许。通常在 softmax 之前给禁止位置加上负无穷，使其指数权重为零；不能先做完整 softmax，再简单把禁止位置乘成零而不重新归一化，因为剩余权重的和通常不再是 1。为每一行保留至少一个可访问位置也是必要前提：一整行全被屏蔽时，朴素 softmax 没有有效的归一化分母，实现必须明确拒绝或定义处理策略。

| 约束 | 允许当前位置读取什么 | 解决的问题 |
| --- | --- | --- |
| 双向、无填充 | 所有输入位置 | 输入整体已知时汇聚两侧上下文 |
| 因果掩码 | 自己和之前的位置 | 自回归预测不能读取未来内容 |
| 填充掩码 | 有效 token 对应的位置 | 不把为对齐长度补出的占位符当内容 |

因果和填充不是互斥模式，两者可以共同决定允许集合。自回归训练虽然可以一次计算多个位置，但输入与预测目标要正确错位，并保持因果掩码，否则会泄漏目标信息。生成时尚未产生的 token 本来就不可用，因此多个新 token 的生成仍有顺序依赖；不能从“注意力可以矩阵并行计算”推导出“整段自回归生成一次完成”。

### 2. 内容匹配不等于顺序表示

不含位置相关处理、也没有固定位置掩码的自注意力，对输入行做同一个排列，会让输出行相应排列。它能根据内容计算关系，却不会仅凭矩阵乘法知道某个 token 原来在第几个位置，因此通常需要额外的位置机制。因果掩码改变可访问关系，但“不能看未来”和“知道具体位置或距离”仍是不同职责，不应把它们合并成同一概念。

原始 Transformer 将位置编码加到输入嵌入上，让后续匹配能够利用位置信息；其他设计也可以在查询、键或注意力分数中引入位置相关变化。理解单头计算时，只需知道位置信息在进入匹配前或匹配过程中发生作用，无须把每种位置方案扩展成平行章节。具体实现必须查明采用的方案，不能把一种模型的位置处理写成所有 Transformer 的固定流程。

## 四、多头怎样组合，为什么注意力不是整个 Transformer

一个注意力头产生一套匹配权重及对应汇聚结果。Multi-Head Attention（多头注意力）使用多组学习得到的投影并行计算，让不同子空间有机会形成不同的信息读取方式，再拼接各头输出并做输出投影。这种设计提供了表达能力，不保证每个头都形成互不重复、可以直接命名的语法功能。

$$
\mathrm{head}_h=\mathrm{Attention}(XW_Q^{(h)},XW_K^{(h)},XW_V^{(h)}),\qquad Y=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_H)W_O.
$$

每个头输出宽度为 $d_v$ 时，拼接结果宽度为 $Hd_v$，因此 $W_O$ 将这个宽度映射回模型需要的输出宽度。常见实现令每头宽度等于 $d_{model}/H$，但这属于一种维度配置，不是“多头”一词本身的定义。合并投影后再 reshape 成多头是实现方法；从语义上仍可理解为多组投影分别匹配与汇聚。

Transformer 层还包含残差连接、归一化和逐位置前馈网络。残差让子层输入能够与其变换结果相加；归一化调整表示的数值分布；前馈网络对每个位置的特征做非线性变换。注意力负责跨位置的信息交互，前馈网络主要负责位置内部的特征加工，两者共同构成层的计算。不同架构会调整归一化位置等细节，不能把单个注意力公式等同于完整层。

Cross-Attention（交叉注意力）沿用相同的匹配与汇聚计算，但查询来自一条序列，键和值来自另一条序列。例如编码器—解码器模型可以用解码器表示查询编码器输出；此时查询长度与键长度可以不同，注意力矩阵为 $n_q\times n_k$。Self 与 Cross 区分的是输入来源，多头区分的是并行投影组数，因果区分的是可访问关系，它们不是同一分类轴上的三个选项。

## 五、用可运行的小例子核对方向与边界

下面只实现单头、二维矩阵、已给定 Q/K/V 的计算，不包括投影训练、多头、batch、dropout 或自动求导。输入约定为非空、维度匹配且元素有限的数值矩阵；`allowed` 是与分数矩阵同形状的布尔矩阵，`True` 表示允许访问。代码用标准库把计算步骤展开，适合对照公式，不是生产环境高性能实现。

```python
from math import exp, sqrt


def attention(q, k, v, allowed):
    scale = sqrt(len(q[0]))
    weights, output = [], []
    for query, row_mask in zip(q, allowed):
        scores = [sum(a * b for a, b in zip(query, key)) / scale for key in k]
        indices = [j for j, keep in enumerate(row_mask) if keep]
        if not indices:
            raise ValueError("each query must have an allowed key")
        peak = max(scores[j] for j in indices)
        numerators = [exp(s - peak) if keep else 0.0
                      for s, keep in zip(scores, row_mask)]
        total = sum(numerators)
        row = [x / total for x in numerators]
        weights.append(row)
        output.append([sum(row[j] * v[j][c] for j in range(len(v)))
                       for c in range(len(v[0]))])
    return weights, output


identity = [[1.0, 0.0], [0.0, 1.0]]
full = [[True, True], [True, True]]
causal = [[True, False], [True, True]]
for name, mask in [("full", full), ("causal", causal)]:
    _, result = attention(identity, identity, identity, mask)
    print(name, [[round(x, 6) for x in row] for row in result])
```

减去当前允许分数的最大值不会改变 softmax 的比例，却能避免直接对很大的正分数取指数。程序应打印 `full [[0.669762, 0.330238], [0.330238, 0.669762]]` 和 `causal [[1.0, 0.0], [0.330238, 0.669762]]`。第二种情况第一行只能读取自己，因此权重成为 $(1,0)$；第二行仍允许读取两个位置，结果不变。若把任一掩码行全部改为 `False`，程序会拒绝计算，不用 NaN 掩盖未定义的输入。

核对实现时应同时检查形状、归一化方向、禁止位置权重和输出内容。仅检查输出形状不足以发现转置或 softmax 轴写反；仅检查每行和为 1 也不足以发现读取了错误的值。这个算例给出可以手算的具体数值，因果版本再单独验证访问边界；更改 V 的实验则用于核对输出确实来自值向量，而非直接返回权重。

## 六、成本、适用边界与进一步核验

对长度为 $n$ 的稠密单头注意力，形成全部成对分数约需 $O(n^2d_k)$ 运算，汇聚值约需 $O(n^2d_v)$ 运算。若实现显式保存整个分数或权重矩阵，其大小为 $n\times n$；batch 和头数还会增加实际存储。这里描述的是注意力核心，不包含输入投影、前馈网络或完整训练状态，不能把它写成整个模型的唯一成本。

二次方的成对计算不意味着每种实现都必须把完整注意力矩阵存入显存。FlashAttention 用分块与重计算等方法减少高带宽显存访问和中间存储，保持精确注意力的目标计算；它不是通过永久删除大部分连接来换取效率。讨论“二次显存”时应说明是否物化了完整矩阵，讨论速度时则要区分运算量、数据搬运和实际硬件条件。[FlashAttention 原论文](https://arxiv.org/abs/2205.14135)说明了这种区别。

阅读或调试一个实际模型时，可以沿本文的计算链核对三件独立的事：Q/K/V 来自哪里且维度是否相容，掩码与位置机制怎样约束匹配，汇聚结果怎样进入多头投影和后续层。缩放点积、多头以及原始编码器—解码器结构的定义可回查[《Attention Is All You Need》§3](https://papers.neurips.cc/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf)；本文没有把后续架构变体当成原论文结论。

> 核验边界：一个局部例子数值正确，只能证明该输入下的计算，不能证明模型训练有效、注意力解释可靠或所有边界都被覆盖。
